# Results

## Raw

- `mistral_small_2603_v1.4.csv`: definitive 324-call LLM output file.
- `baseline_rule_based_v1.0_predictions.csv`: deterministic B0 predictions for the 108 benchmark instances.

## Processed

- `llm_summary_metrics_v1.4.csv`: LLM strategy × representation metrics generated by `scripts/evaluate.py`.
- `strategy_metrics_v1.4.csv`: overall B0/S1/S2/S3 comparison.
- `by_representation_v1.4.csv`: metrics by representation for each method.
- `by_family_v1.4.csv`: metrics by device family for each method.
- `per_capability_f1_v1.4.csv`: F1 for all 16 capabilities across B0/S1/S2/S3.
- `pairwise_exact_match_mcnemar_v1.4.csv`: raw exact McNemar comparisons. The paper applies Holm correction to the three planned LLM-vs-LLM pairwise comparisons.
- The two `.xlsx` files retain the detailed analysis workbooks used during revision.
