# Independent Gold-standard validation

During revision, a second annotator independently re-annotated the 36 source devices using the same frozen 16-capability codebook and primary source documentation.

The annotator was blinded to:

- the original Gold labels,
- all LLM predictions,
- all B0 predictions.

Results:

- 576 binary decisions
- 576 agreements
- 0 disagreements
- observed agreement = 1.000
- Cohen's kappa = 1.000
- exact device-level capability-set agreement = 36/36

The completed workbook is retained for auditability, while the CSV files provide machine-readable decisions and agreement summaries.
